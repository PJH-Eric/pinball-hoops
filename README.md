# 彈珠籃球（pinball-hoops）

只有**一片彈板**的彈珠籃球：球從右邊斜坡滾到彈板上，**點畫面任何地方**（或按空白鍵）彈板就揮起，把籃球打進貼在右牆、開口朝左、會慢慢上下移動的籃框。限時衝分，單機四段難度，也能線上 2～4 人同時玩、其他人觀戰。零依賴（Node 18+，線上測試需要 Node 22+）。

## 玩法與計分
- 球由上往下穿過籃框（從籃框底下往上頂、球心連半顆球都沒高過框線就掉回來的不算分）：碰框進 **20 分**、空心球 **30 分**；7 秒內連進有連擊 ×2…最高 **×5**；撞彈跳墊每下 1 分。
- 線上房間：房主可在空位上直接「加入電腦」（新手／一般／高手）。電腦在伺服器上用同一套規則真的打一局，不是亂編分數。
- 掉落洞口（彈板尖端與左下導板之間的缺口）寬度依難度固定為球寬的倍數：幼幼班 1.1／簡單 1.25／普通 1.5／困難 1.75。
- 難度：幼幼班（籃框超大、有彈力墊不漏球、120 秒）／簡單（5 球）／普通（3 球）／困難（籃框小、移動大又快、彈板短）。
- 操作：點／按住畫面任何地方揮板、放開落下；鍵盤 Space／Z／方向鍵；Esc 暫停（單機）。
- 設定在右上角（背景音樂、音效、震動、減少動態、高對比、鍵盤提示、恢復預設）。

## 執行
```
npm start          # 或雙擊「啟動遊戲.bat」，本機 http://localhost:3200
npm test           # 規則核心＋房間邏輯＋設定解析
npm run test:online# 真的起伺服器，用 3 條 WebSocket 走完整線上流程
npm run verify     # 以上全部
```
也可以直接用瀏覽器開 `public/index.html` 玩單機（線上模式需要伺服器）。

## 線上對戰
- 每位玩家在自己的瀏覽器玩**同一張台**（同難度、同種子），伺服器負責房間、倒數、統一結束時間、收集並檢查分數、廣播排行。
- 房間：公開／不公開、玩家席位 4、觀戰席 20、聊天室、房主可請出玩家。
- **邀請連結**：房主可複製「玩家」或「觀戰」連結；連結只對該房間有效、6 小時過期、可撤銷並重發。被邀請者會先停在大廳，確認暱稱後才加入；角色一律由伺服器依 token 決定。
- **房間生命週期**：房內沒有「連線中的真人玩家」（觀戰者不算）就立即關閉：邀請失效、從大廳移除、通知觀戰者；已關閉的房間不會因重連復活。
- 對局中斷線可在 30 秒內用同一分頁重連，分數保留。
- 分數是玩家端回報，伺服器只做單調遞增與速度上限檢查（不是權威物理），適合朋友間娛樂。

## 部署（預設：GitHub Pages 前端＋Render 後端）
1. 推到 GitHub repo `pinball-hoops`，Pages 來源選 GitHub Actions。
2. Render 以 `render.yaml` 建立 Web Service（region 固定 `singapore`），環境變數 `ALLOW_ORIGIN` 填 Pages 網址。
3. 在 repo 的 Actions Variables 設 `GAME_SERVER_URL`＝Render 的 HTTPS 網址（也可手動執行 workflow 時填）。
4. 前端只從 `public/js/config.js` 讀取伺服器位置（優先序：`?server=` → 建置注入 → 同源），不寫死網址、不回退 localhost。
- Render 免費方案會休眠，前端會顯示「喚醒伺服器中」；房間只存在記憶體，重啟後消失。
- 健康檢查：`/health`；遊戲大廳（game-lobby）人數：`/api/presence`，回傳 `online／players／spectators／lobby／rooms`。

## 目錄
`public/js/rules.js` 規則與物理（瀏覽器與伺服器共用）／`render.js` Canvas 繪圖／`audio.js` 合成音效（無外部音檔）／`net.js` 連線／`app.js` 畫面；`lib/rooms.js` 房間邏輯；`server.js` HTTP＋WebSocket。

## 美術方向
夜間街頭球場＋霓虹燈管：瀝青深藍、球場橘漆線、霓虹青／洋紅／螢光黃燈管；斜切角貼紙式按鈕；全部為向量繪製，無 emoji 文字。音效與音樂為即時合成，日後要換正式素材只需改 `audio.js`。

## 已知限制
- 與 MSN 原版只在玩法概念上相近（單板、點擊揮板、投籃），美術、音效、程式皆為原創。
- 手機直向以外的極端比例（寬高比接近 1:1 的小視窗）畫面會縮小以保持操作空間。
