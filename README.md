# 彈珠籃球（pinball-hoops）

只有一片彈板的街機投籃遊戲：球從右邊斜坡滾下來，點住畫面或按住按鍵揮板，把球打進貼在右牆、開口朝左的移動籃框。單機四段難度，對局紀錄與成就保存在本機瀏覽器。

## 玩法與計分

- 球由上往下穿過籃框：碰框進 20 分、空心球 30 分；7 秒內連進有連擊倍率，最高 ×5。
- 每 20 秒開始 5 秒加分時段，進球額外加 10 分，不受連擊倍率影響。
- 擊球區提示可在設定關閉；連擊顯示剩餘秒數。
- 掉落洞口寬度依難度固定為球寬的倍數：幼幼班 1.1、簡單 1.25、普通 1.5、困難 1.75。
- 難度：幼幼班（籃框超大、有彈力墊不漏球、120 秒）／簡單（5 球）／普通（3 球）／困難（籃框小、移動大又快、彈板短）。
- 操作：點／按住遊戲畫面揮板，放開落下；鍵盤 Space／Z／方向鍵；Esc 暫停。
- 設定在右上角（背景音樂、音效、震動、減少動態、高對比、鍵盤提示、恢復預設）。

## 執行

需要 Node.js 26.12.1 或更新的 26.x 修補版，不需安裝套件：

```text
npm start
```

接著開啟 `http://localhost:3200`。也可以直接用瀏覽器開啟 `public/index.html`。

## 部署

遊戲是純靜態單機頁面，可用 GitHub Pages 發布。GitHub Actions 會執行現有驗證與 SEO 注入，再部署 `public/`；不需要遊戲伺服器或環境變數。

## 目錄

- `public/js/rules.js`：遊戲規則與物理。
- `public/js/render.js`：Canvas 繪圖。
- `public/js/audio.js`：即時合成音效與音樂。
- `public/js/app.js`：遊戲畫面、操作與設定。
- `public/js/storage.js`：本機紀錄、成就與設定。

## 美術方向

夜間街頭球場加霓虹燈管：瀝青深藍、球場橘漆線、霓虹青／洋紅／螢光黃燈管；斜切角貼紙式按鈕。畫面採向量繪製，音效與音樂即時合成。

## 維護與驗證產物

介面支援繁體中文、簡體中文與英文；從右上角語言按鈕切換。截圖、測試報告、記錄檔及快取為可重新產生的驗證產物，不屬於正式遊戲資產，也不提交版本控制。
